从排行榜、统计推断到 RL Environment

不是教「怎么跑一个 benchmark」。leaderboard 分数 ≠ 模型能力。 七个因子里只有一个是 model。

performance = Model × Harness × Environment × Task × Budget × Scorer × Randomness
测得的性能是这七项的乘积。换 harness、换资源上限、换 user simulator,数字会动 —— 模型可以没变。

这门课训练的四件事

现有课程能覆盖工具使用,但没有一门同时覆盖统计学 + benchmark 设计 + environment + evaluation integrity + on-policy RL。

1能读懂并质疑排行榜
2能设计有统计可信度的 agent benchmark
3能搭建可复现、隔离、可验证的 agent environment
4能让同一套 infra 同时服务 evaluation 与 on-policy RL
